# adocate-ai
An AI-powered Legal Assistant built with Flask, SQLite, and Gemini AI that helps clients and advocates manage cases, generate legal reports, upload documents, and receive AI-powered legal guidance.
# ⚖️ AI Advocate

AI Advocate is an AI-powered legal assistance platform developed using **Python Flask**, **SQLite**, and **Google Gemini AI**.

It helps both clients and advocates manage legal cases efficiently while providing AI-powered legal assistance.

---

## 🚀 Features

### 👤 Client
- Register/Login
- Create New Case
- Upload Documents
- AI Legal Assistant
- Appointment Booking
- Track Case Status
- View Reports

### ⚖️ Advocate
- Advocate Dashboard
- View Assigned Cases
- Manage Clients
- Generate Legal Reports
- Update Case Status
- AI Assistance

### 🤖 AI Features
- Gemini AI Integration
- Legal Question Answering
- Case Summary Generation
- Legal Draft Suggestions
- Document Analysis
- Intelligent Recommendations

## Installation

Clone Repository

```bash
git clone https://github.com/yourusername/AI-Advocate.git
```

Go to project

```bash
cd AI-Advocate
```

Install packages

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
